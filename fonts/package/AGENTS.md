## Lensa Hand handwriting font

This project uses the "Lensa Hand" handwriting font from the `lensa-hand` package. Before applying
it, read the package's `SKILL.md` (in `node_modules/lensa-hand/` or wherever the package lives in
this repository). It covers CSS, Next.js, Tailwind, React Native and Flutter, lists the
covered characters, and sets the rules: keep a fallback font, use only the regular weight,
keep code in monospace.
