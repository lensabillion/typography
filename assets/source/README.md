# Private source material

Place the original alphabet photograph at `alphabet.jpg`.
The supplied photograph has been copied here locally so the build does not rely on
Telegram's temporary storage. Photos in this directory are ignored by Git and
excluded from distributions and font bundles.

The crop map in `config/alphabet.json` describes this particular photograph.
A different sheet needs its own crop map. Do not stretch, rotate or crop the source
without updating the coordinates.
